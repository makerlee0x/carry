# Security

If you find something that could put user funds at risk, please report it privately through
[GitHub security advisories](https://github.com/makerlee0x/carry/security/advisories/new)
instead of opening a public issue or posting it on social media.

Include the network, contract address, and steps or a transaction that shows the problem.
We'll confirm we got it and keep you updated until it's fixed.

Known findings from internal reviews are tracked in [`docs/SECURITY_V3.md`](./docs/SECURITY_V3.md).
