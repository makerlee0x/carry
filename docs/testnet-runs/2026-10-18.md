# Testnet read-only run, 2026-10-18

Read-only pass for [#11](https://github.com/makerlee0x/carry/issues/11). Every value below came from
`eth_call` / `eth_getTransactionReceipt` against `https://rpc.testnet.chain.robinhood.com` (chain
46630, block ~137,740,795, 2026-10-18 ~02:45 UTC). No transactions were sent. "Simulated" means an
`eth_call` of the write function from the named address, which shows what a real tx would do at
that block without changing state.

The node is not an archive node (`missing trie node` for old blocks), so balances before/after old
txs can't be read back; flow results come from the events in each receipt.
